1 [listening state]:input: continuous audio stream; function: real-time voice activity detection (VAD) and audio signal reception; transmits received audio to llm; output: wake signal / trigger signal to start processing

2 [talking state]:input:human voice; function: respond human talking; output: robot voice




3 [name state]:the state which identifies person by the name



4 [navigation state]:the state which takes 3d position on map as input and drive robot to the place



5 [gest/pose recognition state]:the state which observes and identifies person with a specific pose/gesture, then output its position 



15 [gest/pose counting state]:the state which observes and identifies people with a specific pose/gesture, then output total number



6 [person tracking state]:the state which keeps track of a person and output its live 3d position


7 [clothes recognition state]:the state which observes and identifies person by the clothes color, then output its position 


17 [clothes counting state]:the state which observes and identifies person by the clothes color, then output total number


8 [object search state]:the state which looks for an object by its name and output its live 3d position 


9 [object grasp state]:the state which grasps an object, the object is given by its name


10 [object dump state]:the state which the robot lets go of the object it is grasping, the position is given by 3d position
